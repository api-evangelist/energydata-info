# ENERGYDATA.info (energydata-info)

ENERGYDATA.info is a organization open-data portal running **CKAN**, exposing a standardized catalog API over ~1,190 datasets.

**URL:** [Visit APIs.json URL](https://raw.githubusercontent.com/api-evangelist/energydata-info/refs/heads/main/apis.yml)
